## How to use it
1. Cover the answer, say yours out loud for 60 seconds, then compare.
2. Mark questions you miss; redo them after 1 day, 3 days and 1 week.
3. For each one, find the matching deeper note: Python/, SQL/, Backend/, HLD/, ML/, DL/, GenAI/.
4. Tie every answer to one of your own projects (Healthcare booking, Placement Portal, Smart MCQ, FinSight) so it sounds experienced.
