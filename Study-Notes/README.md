# Study Notes (DSA, Python, SQL)

Reference notes compiled on 19 Nov 2026 for interview preparation, written from ELI15 explanations up to expert depth, with Python and C++ code where relevant.

**How these were made, honestly:** an AI assistant wrote them after reading official documentation and company interview pages (listed in each `SOURCES.md`). Statements checked against an official source are marked **Est.**; standard knowledge or my own examples that were not verified are marked **Ex.** The notes have **not been tested or assessed**, and the SQL examples were not run against a database. Treat them as drafts: verify before relying on them, and fix any mistake you find.
